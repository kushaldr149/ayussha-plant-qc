Test frequency for cement, SCM, microsilica and fibre sets

Aggregate test frequencies come from the BIS product manual for IS 383, which the manual calls recommendatory. All frequencies and limits can be changed afterwards per parameter. Chemical admixtures are product-specific: add each one (for example a Fosroc or Sika product) with "Add material" in the Admixture category, then apply the IS 9103 set with the manufacturer's stated values.

Aggregate limits are from IS 383:2016 (Third Revision) base text, Table 2 read from the BIS page image. Where Table 2 has no requirement for a type (for example shale in crushed stone sand, soft fragments in crushed coarse aggregate), that test is not added. {% include "_cement_note.html" %}
